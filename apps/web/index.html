Use the API

OpenAI-compatible. Point any OpenAI SDK at this host. Get a free key (250k tokens/day) via POST /keys; keyless calls get 4k tokens/day.

curl https://HOST/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer mc_YOUR_KEY" \
  -d '{
    "model": "qwen2.5-3b-q4km",
    "messages": [{"role":"user","content":"Hello!"}]
  }'

Add "stream": true for SSE streaming. GET /v1/models lists what the grid serves right now.

Donate your GPU

  • Download the MassCompute worker (Windows installer or portable — macOS/Linux builds on the roadmap).
  • Pick a model tier that fits your VRAM, set idle thresholds, hit Donate.
  • Only pinned, SHA-256-verified open-weight models run — no arbitrary code, ever. Prompts transit your machine; don't donate if that's not okay.
  • The node stays idle while you use the PC (idle timer, GPU-busy detection, battery check, optional schedule).
# CLI alternative (developers)
npm install -g @masscompute/worker
masscompute --coordinator wss://HOST --donate
